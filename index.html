About Me

I'm a Frontend Developer with a Computer Science background, focused on building modern, responsive, and user-friendly web experiences. I care about how an interface feels as much as how it looks — clear layouts, smooth interactions, and interfaces that make sense the first time someone uses them.

My work centers on HTML, CSS, JavaScript, and React, and I build every project on clean, maintainable code so it's easy to extend later — whether that's a new business website, a landing page, or a full React interface. I'm a continuous learner, always refining how I structure UI and solve problems in the browser.

Featured Projects

My final year project, alongside a few concept builds that show how I approach frontend work.

Featured — Final Year Project · 2025

AI Traffic Monitoring System

An intelligent traffic monitoring system using drone-mounted cameras and AI-based computer vision to analyze real-time traffic conditions.

Overview

Built to improve traffic management, the system processes live aerial footage through machine learning models to detect vehicles, measure traffic flow, identify congestion, and generate useful traffic insights.

Why it matters

Drone-based monitoring offers a cost-effective, scalable alternative to fixed traffic cameras, making it a practical fit for smart-city planning and large-area traffic monitoring.

  • AI-based vehicle detection
  • Real-time traffic monitoring
  • Drone-based aerial footage
  • Traffic flow analysis
  • Congestion identification
  • Computer vision-based analysis
